Independent project · 2022–2023

Upturn

A low-poly multiplayer arena shooter where players compete to outgun one another—and defeated players return stronger.

Role
Gameplay Programmer
Genre
Multiplayer FPS
Technology
Unity · C#
Networking
Photon PUN

Overview

Learning multiplayer through a complete game loop

Upturn was my first substantial 3D project and an opportunity to move beyond local gameplay into networked player interactions. The game combines arena movement, multiple weapons, competitive matches, defeat, respawning, and a comeback system.

The defining mechanic gives struggling players more power after being defeated. This keeps a match moving and gives players who fall behind a way to remain involved.

My contribution

Core multiplayer systems

The project focused on connecting recognizable shooter mechanics with networked state and match flow.

01

Networked gameplay

Implemented multiplayer interactions in Unity using Photon PUN and learned to reason about state shared between players.

02

Weapons and combat

Developed multiple weapons and supporting gameplay systems to create distinct combat choices.

03

Respawn and comeback loop

Takeaways

What the project taught me

Shared state matters

Multiplayer features require clear ownership and consistent outcomes across every connected player.

Feedback supports fairness

Players need understandable weapon, damage, defeat, and respawn feedback during fast matches.

Mechanics shape pacing

The comeback system showed how one rule can change the emotional arc of an entire match.
